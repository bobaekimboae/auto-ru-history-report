# Auto.ru Inspired Korean Vehicle History Report

Auto.ru vehicle history sample report structure adapted into a Korean used-car history report demo.

## What is included

- Koreanized report terminology for 자동차등록원부, 신규등록, 이전등록, 소유자 변경, 보험 이력, 성능·상태점검, 정기검사, 압류·저당.
- Interactive vehicle lookup sample, timeline filters, expandable timeline details, mileage list/chart switch, accordion FAQ, VIN copy, and photo dialog.
- User-provided Auto.ru SVG icon assets under `assets/icons/`.
- Static GitHub Pages deployment through GitHub Actions.

## Source reference

- Auto.ru history page: https://auto.ru/history/
- Captured reference notes are local only and not published.

This is a public UI demo. It does not perform real vehicle-history lookup.

## 매물사진 배경지우개 (`bg-remover/`)

중고차 딜러용 매물 사진 배경 제거 도구입니다. `/bg-remover/` 경로로 열면 됩니다.

- 여러 장을 끌어다 놓으면 차례대로 AI가 배경을 지웁니다. 사진은 서버로 보내지 않고 브라우저 안에서만 처리합니다.
- 배경: 상사 쇼룸(화이트·블랙), 스튜디오, 그레이 쇼룸, 다크 쇼룸, 순백색, 단색, 내 배경 사진, 투명(PNG)
- 상사 쇼룸: 슬랫 벽에 상사명·로고·문구를 입체 간판으로 넣은 가상 스튜디오. 간판 자리를 고정해 모든 사진에서 같은 크기로 보입니다.
- 차량 아랫선을 따라 그리는 바닥 그림자와 바닥 반사, 4:3·1:1·16:9·원본 비율, 차량 크기와 바닥 높이 조절
- 지우개·복원 붓으로 남은 배경을 다듬고, 되돌리기와 원본 비교(스페이스 키)를 지원합니다.
- 실내·계기판 사진은 "배경 유지"로 두면 비율과 상사 정보만 맞춥니다.
- 상사명·연락처·로고를 하단 띠나 오른쪽 아래 라벨로 넣을 수 있고, 이 정보는 브라우저에 기억됩니다.
- 파일 이름 앞부분(예: 차량번호)을 정해 JPG/PNG로 한 장씩 또는 ZIP으로 한 번에 저장합니다.

합성 도구(마스크 정리·그림자·반사·상사 쇼룸)는 `bg-remover/compose.js`에 있고 숏폼 스튜디오도 같이 씁니다.

AI 모델은 [onnx-community/ISNet-ONNX](https://huggingface.co/onnx-community/ISNet-ONNX)(AGPL-3.0)를 [Transformers.js](https://github.com/huggingface/transformers.js)로 실행합니다. 첫 실행 때 모델(약 42~84MB)을 내려받고 이후에는 브라우저 캐시를 씁니다. fp16을 지원하는 그래픽카드가 있으면 WebGPU로, 없으면 CPU로 처리합니다.

로컬에서 확인하려면 저장소 루트에서 `python3 -m http.server`를 실행하고 `http://localhost:8000/bg-remover/`를 엽니다. 모듈 워커를 쓰기 때문에 파일을 직접 여는 방식(`file://`)으로는 동작하지 않습니다.

## 매물 숏폼 스튜디오 (`studio/`)

중고차 딜러가 차량을 등록해 두고 매물 사진으로 릴스·쇼츠·틱톡용 숏폼 영상을 만드는 대시보드형 도구입니다(OnlyCars 흐름 참고). `/studio/` 경로로 엽니다.

- 대시보드: 등록 차량·영상 완료·영상 대기 현황과 차량 카드 목록
- 차량 등록: 차량번호(관리번호), 제조사·모델·등급, 연식, 주행거리, 연료, 변속기, 사고 이력, 가격, 강조 포인트, 사진 업로드·순서 변경·대표 사진 지정
- 영상 만들기: 세로 9:16 / 정사각 1:1 / 가로 16:9, 템플릿 3종(클린·다이나믹·럭셔리), 15·30초, 가격 표시, 마지막 장면 문구, 실시간 미리보기
- 매물 사진: "만들 것"에서 매물 사진을 고르면 모든 사진을 등록용 4:3(1600×1200) 또는 1:1로 만들어 ZIP으로 저장합니다. 자동 보정(밝기·대비·색감), 선명하게, 상사 배너(로고·상사명·차량명·가격·연락처), 쇼룸 배경, 번호판 가리기가 한 번에 적용됩니다.
- 실내 사진 자동 판별: ResNet-18 분류로 외관과 실내·엔진룸·계기판을 가려, 실내 사진은 쇼룸·턴테이블·번호판 가리기에서 빼고 원본을 씁니다.
- 배경 지우기 보정: 하늘이 비친 보닛·유리처럼 차체 안쪽에 뚫린 구멍은 차의 일부로 채웁니다.
- 턴테이블 영상·360° 회전: "만들 것"에서 턴테이블을 고르면 배경을 지운 외관 사진(최대 12장)을 쇼룸 회전 무대 위에 세워 차가 도는 영상을 만듭니다. 미리보기를 손으로 끌면 360°로 돌려볼 수 있고, 쓸 사진은 썸네일을 눌러 빼거나 넣습니다. 권장 촬영: 45°마다 8장(앞 → 왼쪽 앞 사선 → 왼쪽 옆 → 왼쪽 뒤 사선 → 뒤 → 오른쪽 뒤 사선 → 오른쪽 옆 → 오른쪽 앞 사선), 최소 4장.
- 번호판 가리기: 번호판 전용 AI(YOLOS, 브라우저 안에서 실행)가 사진마다 번호판을 찾아 상사 번호판(상사명·연락처)이나 모자이크로 덮습니다. "번호판 위치 확인·수정" 창에서 네 모서리를 끌어 맞추거나 지울 수 있고, 차량 편집의 사진마다 있는 "번호판" 버튼으로도 고칠 수 있습니다.
- 3D 쇼룸 배경 6종(화이트·블랙·콘크리트 갤러리·우드 라운지·모던 차고·상사 컬러 월): three.js로 광택 바닥 반사, 천장 조명, 벽 재질, 상사 색 LED 원형 무대, 조명 받은 상사 간판이 있는 공간을 브라우저에서 렌더링해 차를 세웁니다. WebGL이 안 되는 기기에서는 평면 쇼룸 그림으로 대신합니다.
- AI 나레이션: 매물 정보로 대본을 자동으로 쓰고(고쳐 쓰기·다시 쓰기 가능), Supertonic 2(Supertone, OpenRAIL-M) 음성 AI가 브라우저 안에서 한국어로 읽어 영상에 넣습니다. 목소리 10종(여성 5·남성 5), 말 빠르기 4단계를 고를 수 있고, 숫자는 소리 나는 대로 바꿔 읽습니다(1,890만 원 → 천팔백구십만 원). 나레이션이 나오는 동안 배경음악은 자동으로 낮아집니다. 처음 한 번 음성 AI(약 260MB)를 내려받습니다.
- 배경음악 고르기: 템플릿에 맞춤, 합성 음악 7곡(산뜻한 팝·파워 비트·럭셔리 라운지·로파이 칠·힙합 그루브·하우스 EDM·시네마틱), 내 음악 파일 올리기(시작 위치 지정), 음악 없음 중에서 고릅니다. 곡마다 ▶로 10초 미리 들을 수 있습니다. 합성 음악은 Web Audio로 직접 만들어 저작권 걱정이 없습니다.
- 사진 슬라이드: 틱톡 사진 게시물·인스타 캐러셀용으로 표지 1장 + 사진마다 1장(정보 카드 포함) + 마무리 1장을 만듭니다(최대 35장). 9:16·4:5·1:1·16:9, 템플릿·상사 쇼룸 배경을 그대로 쓰고 ZIP으로 저장하거나 휴대폰에서 바로 공유합니다.
- 영상은 브라우저에서 녹화해 저장합니다. H.264를 지원하는 크롬·엣지에서는 MP4, 그렇지 않으면 WebM으로 저장됩니다.
- 게시 문구(차량 정보·강조 포인트·연락처·해시태그)를 자동으로 만들어 복사할 수 있습니다.
- 배경을 "상사 쇼룸"(화이트·블랙)으로 고르면 배경지우개의 AI로 사진마다 배경을 지우고, 상사명 간판이 있는 가상 쇼룸에 차를 세워 영상을 만듭니다. 지운 결과는 저장돼 다음부터 바로 쓰이고, "실내"로 표시한 사진은 원본 그대로 나옵니다.
- 상사 설정(상사명·연락처·지역·브랜드 색·로고·기본 문구·해시태그)은 모든 영상에 적용됩니다.
- 첫차 매물 가져오기: 매물 사진(최대 20장)과 차량 정보(제조사·모델·등급·연식·주행거리·연료·변속기·색상·사고 여부·가격·강조 포인트·설명)를 가져와 차량을 만들고 영상 화면을 바로 엽니다.
  - 즐겨찾기 버튼: 대시보드의 "첫차 → 숏폼 보내기" 버튼을 즐겨찾기 막대에 끌어다 놓고, 첫차 매물 상세 페이지에서 누릅니다. 서버 없이 동작합니다.
  - 링크 붙여넣기: 매물 링크나 검색 목록 링크를 붙여넣습니다. 중계 함수 `api/listing.js`가 필요해서, 이 저장소를 Vercel에 연결해 배포하면 같은 사이트의 `/api/listing`으로 자동으로 켜집니다(GitHub Pages에서는 즐겨찾기 버튼만 보입니다).
  - 첫차 데이터 변환은 `lib/chutcha.js`에 있고 중계 함수와 스튜디오가 같이 씁니다.
  - 상사 쇼룸 배경은 영상에 나오는 사진만 처리하고, 실내·계기판·기어봉 같은 근접 사진은 자동으로 원본을 씁니다.
- 차량과 사진은 서버가 아니라 이 브라우저(IndexedDB)에만 저장됩니다.
## 딜러 숏폼 메이커 (`shortform/`)

매물 사진 몇 장과 차량 정보로 릴스·쇼츠·틱톡용 중고차 숏폼 영상을 만드는 딜러용 도구입니다. `/shortform/` 경로로 열면 됩니다. [ReelsMotor](https://reelsmotor.com/create)의 "사진 → 상세 정보 → 스타일" 3단계 흐름을 따르되, 서버 없이 브라우저 안에서 영상을 녹화합니다.

- **1단계 사진**: 3~10장, 첫 사진이 첫 장면입니다. 끌어서 또는 ‹ › 버튼으로 순서를 바꾸고, 사진마다 부위 이름(측면·실내·엔진룸 등)을 자막으로 붙입니다. "번호판 가리기"로 네모를 그리면 그 부분을 모자이크합니다.
- **2단계 차량 정보**: 제조사·모델·연식(필수), 세부 등급, 주행거리, 가격(만원), 색상, 연료, 변속기, 차종, 특장점(최대 6개, 자주 쓰는 문구 버튼 제공). 첫 장면에 차량 이름·연식·가격이 크게 나오고, 이후 사진마다 사양과 특장점이 하나씩 강조됩니다.
- **3단계 스타일·만들기**: 강렬하게 / 깔끔하게 / 역동적으로 3가지 스타일, 9:16·1:1·16:9 비율, 전체 보기(흐린 배경)·꽉 채우기, 길이(자동·15초·30초).
- **배경음악**: 저작권 걱정 없도록 브라우저에서 직접 합성합니다. 차종·연료·가격으로 분위기를 자동 추천하고(SUV → 경쾌한, 전기차 → 미래적인, 5천만원 이상 세단 → 고급스러운 등), 장면 전환을 박자에 맞춥니다. 내 음악 파일을 쓰거나 끌 수도 있습니다.
- **상사 정보**: 상사명·연락처·로고·강조 색·마무리 문구가 위쪽과 마지막 화면에 들어가며 브라우저에 기억됩니다. 배경지우개에 입력해 둔 상사 정보가 있으면 처음에 불러옵니다.
- **완성**: 영상(MP4, 지원하지 않는 브라우저에서는 WebM)과 썸네일 JPG를 저장하고, 게시글 문구와 해시태그를 자동으로 만들어 복사할 수 있습니다. 휴대폰에서는 공유 버튼으로 바로 앱에 올릴 수 있고, 같은 내용으로 다른 비율 영상도 만들 수 있습니다.

영상은 `canvas` + `MediaRecorder`로 실시간 녹화하므로 영상 길이만큼 시간이 걸리고, 그동안 탭을 열어 두어야 합니다(다른 탭으로 가면 녹화를 잠시 멈췄다가 돌아오면 이어서 녹화합니다). 인스타그램용 H.264 MP4는 최신 Chrome·Edge·Safari에서 만들어집니다. 로컬에서는 저장소 루트에서 `python3 -m http.server`를 실행하고 `http://localhost:8000/shortform/`을 엽니다.
