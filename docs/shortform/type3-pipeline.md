# ③ 에이전트 MCP 편집 파이프라인 (설계 초안)

작성: 서울오토갤러리 자동 영상 제작 코덱스 마스터 · 2026-11-07 · 상태: **초안**
담당: ③유형 제작·규정·파이프라인 (노션 의견 페이지 0번 항목 기준)
규정: `docs/shortform/listing-rules.md`

## 1. 목표

딜러가 **사실표 + 사진/짧은 영상 + 한 줄 설명**만 주면, 등록 규정(`listing-rules.md`)에 맞는 세로 숏폼 초안을 자동으로 만든다. 딜러는 확인만 한다.

## 2. 단계

```
[1 입력] → [2 사실 검증] → [3 소재 정리] → [4 편집 생성] → [5 자동 점검] → [6 딜러 확인] → [7 게시·기록]
```

| 단계 | 하는 일 | 실패 시 |
| --- | --- | --- |
| 1 입력 | 사실표(규정 3번), 사진·영상 소재, 한 줄 설명 수집 | 빈칸 목록을 딜러에게 돌려준다 |
| 2 사실 검증 | 사실표 값 형식 확인 (연식·주행거리·가격 숫자, 안심번호 형식) | 보류 |
| 3 소재 정리 | 사진 순서·훅 장면 선정, 번호판 위치 표시 | 소재 부족 시 보류 |
| 4 편집 생성 | 나레이션(TTS) · 자막 · 포인터(화살표·원) · 음악 · 끝 화면을 편집기에서 조립 | 재시도 1회, 그래도 실패면 보류 |
| 5 자동 점검 | 길이·비율·자막 줄 수·번호판 블러·빈칸·가격 표기 일치 | 규정 위반 항목 표시 후 재편집 |
| 6 딜러 확인 | 초안 링크 전달, "확인" 응답을 받는다 | 확인 없으면 게시 안 함 |
| 7 게시·기록 | 승인된 것만 게시. 제작 기록(사실표 버전, 음악 출처, 게시 시각) 저장 | — |

## 3. 도구 (편집 엔진 후보)

| 도구 | 역할 | 현재 상태 (2026-11-07) |
| --- | --- | --- |
| 어도비 프리미어 프로 MCP (adobe-premiere-pro-mcp 1.2.11) | 세로 편집·자막·타임라인 | 설치 완료. 프리미어 안 MCP Bridge 패널 실행 전이라 편집 불가 |
| 챗컷(ChatCut) MCP | 자막·컷 자동화 | 코덱스에 등록됨. 연결 시험 필요 |
| 캡컷 플러그인 | 자막 스타일 적용 | 플러그인 있음. 자동화 범위 확인 필요 |
| Shotstack · OpusClip · Tella MCP | 대안·비교 후보 | 등록됨. 시험 전 |
| TTS: 타입캐스트 · 수퍼톤 · 일래븐랩스 | 나레이션 | 미정. 목소리·비용 결정 후 선택 |
| 음원 라이브러리 | 배경 음악 | 미정 (출처 확정 전 음악 없이) |

편집 엔진은 하나를 기본으로 정하고, 나머지는 같은 입력으로 비교 시험한다. 기본 엔진 확정은 사용자 결정 사항.

## 4. 입력·출력 형식 (제안)

입력 (딜러 제출, JSON):

```json
{
  "dealer_account": "계정명",
  "vehicle": {
    "make_model": "포르쉐 911 카레라",
    "year": 2022,
    "mileage_km": 12300,
    "price_krw": 198000000,
    "options": ["스포츠 크로노", "PASM"],
    "accident_history": "무사고",
    "plate_masked": true
  },
  "assets": ["photo_01.jpg", "video_01.mp4"],
  "one_line": "주행거리 짧고 옵션 풀인 911"
}
```

출력: 9:16 MP4 초안 1개, 자동 점검 결과 JSON, 제작 기록 JSON (사실표 버전·음악 출처·엔진 이름·게시 상태).

## 5. 보류 항목 (사용자 결정 필요)

1. 구독 금액과 월 건수
2. TTS 기본 목소리(남·여, 톤), 딜러 목소리 복제 허용 여부
3. 배경 음악 출처
4. 샘플 게시 계정 (딜러 계정 직접 vs 공식 계정 먼저)
5. `OPENAI_API_KEY` 등록 (릴스 전사용) — 릴스 분석 1단계 막힘 해제 조건

## 6. 다음 작업 순서

1. 릴스 분석 막힘 해제 (전사) → `dealer-reel-analysis.md` 완성
2. 편집 엔진 1개 연결 시험 (프리미어 Bridge 실행 후 샘플 1건)
3. 샘플 1건을 딜러 1명에게 보여 주고 규정 초안 검증 → `listing-rules.md` 확정
4. 같은 흐름을 서울오토갤러리 딜러 전원의 현재 매물 1대씩에 적용 (무료 샘플)
