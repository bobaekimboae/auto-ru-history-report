# 인스타·유튜브 검색·수집 도구 조사

작성: 서울오토갤러리 자동 영상 제작 코덱스 마스터 · 2026-11-21
용도: 딜러 릴스·나사르 쇼츠 분석(1단계)의 막힘 해제 — 릴스 mp4·음성 확보, 계정별 릴스 목록, 키워드 검색, 자막 추출.
버전은 2026-11-21 PyPI·npm에서 직접 확인한 값이다. GitHub 별 수는 이 세션에서 GitHub API 접근이 막혀 확인하지 못했다.

## 1. 결론 (추천 조합)

1. **릴스·쇼츠 파일 받기: `yt-dlp`** — 인스타 릴스와 유튜브 쇼츠의 영상·음성·자막을 한 도구로 받는다. "한지훈 39개 mp4 없음" 막힘을 푸는 1순위.
2. **받은 음성 받아쓰기: Whisper(로컬)** — 지금 막힌 `OPENAI_API_KEY` 대신 Thinkbook에서 로컬로 돌리면 키가 필요 없다.
3. **키워드로 릴스 찾기: Firecrawl의 ScrapeCreators** (이미 연결됨, 건당 2크레딧) — `instagram/search-reels`, `instagram/user-reels`.
4. **유튜브 자막·검색 MCP: `@coyasong/youtube-mcp-server`** — 키 없이 자막, 유튜브 API 키를 넣으면 검색·댓글까지.

## 5. 사용 규칙

- 공개 계정만, 내부 분석 용도로만 쓴다. 받은 딜러 영상을 재게시하거나 우리 영상에 그대로 넣지 않는다.
- 인스타 로그인이 필요한 도구는 회사 업무용 계정으로만 쓰고, 요청 속도를 낮춘다.
- 분석에서 가져오는 것은 길이·컷·훅·자막 모양·말하는 순서 같은 **구조**다. 문장은 베끼지 않는다 (노션 감수 기준 7번).

## 6. 검증 상태

- 버전 확인: 완료 (PyPI·npm 조회).
- 실제 실행: **미실시**. 이 클라우드 세션은 외부 패키지 실행이 승인되지 않는다. Thinkbook에서 `yt-dlp`로 한지훈 릴스 1개를 받아 보는 것이 첫 시험이다.
