# 매물 숏폼 등록 규정 (③ 에이전트 편집 유형)

작성: 서울오토갤러리 자동 영상 제작 코덱스 마스터 · 2026-11-07 · 상태: **초안 (사용자 확인 전)**
적용 대상: 서울오토갤러리 딜러가 인스타·보배드림에 올리는 매물 릴스 전부.
근거: `docs/shortform/dealer-reel-analysis.md`, 노션 의견 페이지(https://app.notion.com/p/411ee9c4b60680f38b96e5b036473a89).

표시 규칙: **확정** = 사용자 결정 또는 법·플랫폼 조건. **잠정** = 릴스 분석 전 임시 값, 분석 후 바꾼다.

## 1. 영상 형식

| 항목 | 기준 | 상태 |
| --- | --- | --- |
| 화면 비율 | 9:16 세로 (1080×1920) | 잠정 |
| 길이 | 30~60초 | 잠정 (한지훈 릴스 약 54초 메모 기준) |
| 컷 길이 | 1~2초 | 잠정 (노션 메모 기준) |
| 첫 3초 | 훅 문구 한 줄 + 차량 전경 (노란 글씨) | 잠정 |
| 끝 화면 | 3초 이상, 딜러 명함(안심번호) + 매장명 | 확정 (안심번호 원칙) |
| 원본 훼손 | 차 화면은 자르기·순서·흐림만. 색·차체·번호판 외 합성 금지 | 확정 |

## 2. 자막

| 항목 | 기준 |
| --- | --- |
| 글꼴·색 | 흰 글씨, 검정 테두리 |
| 강조 | 숫자(가격·주행거리·연식)만 노랑 |
| 줄 수 | 한 화면 최대 2줄, 한 줄 14자 안팎 |
| 내용 | 매물 사실표(아래 3번)에 있는 값만. 과장 표현·비교 우위 주장 금지 |

## 3. 매물 사실표 (영상 제작 전 필수 입력)

영상은 아래 값이 전부 채워져야 만든다. 빈칸이 있으면 제작 보류.

| 필드 | 예시 | 필수 |
| --- | --- | --- |
| 제조사·모델·등급 | 포르쉐 911 카레라 | 예 |
| 연식 | 2022 | 예 |
| 주행거리 | 12,300 km | 예 |
| 판매가 | 1억 9,800만 원 | 예 (가격 미정이면 "문의") |
| 주요 옵션 | 스포츠 크로노, PASM | 예 (최대 3개) |
| 사고·수리 이력 | 무사고 / 판금 1곳 | 예 (숨기지 않는다) |
| 차량번호 | 영상에서 가림 처리 | 예 |
| 딜러명·안심번호 | 050 번호 | 예 |

## 4. 음성 (TTS 또는 딜러 본인)

- 기본: TTS 나레이션. 목소리는 사용자 결정 전까지 **미정** (노션 5번 항목).
- 딜러 본인 목소리 복제는 **본인 동의서가 있을 때만**. 동의 없이 복제하지 않는다.
- 나레이션 문장은 3번 사실표 값만 쓴다.

## 5. 음악

- 저작권 없는 음원 라이브러리에서만 사용. 출처를 제작 기록에 남긴다. (출처 확정 전 음악 없이 제작)
- 인스타 앱 내 음원은 자동 제작물에 넣지 않는다.

## 6. 개인정보·광고 규정

- 개인 휴대폰 번호 금지. 050 안심번호만 노출.
- 차량번호판은 영상에서 블러 처리.
- 사실과 다른 가격·옵션·무사고 표기 금지. 사실표와 다르면 게시하지 않는다.

## 7. 검수와 게시

| 단계 | 담당 | 통과 기준 |
| --- | --- | --- |
| 자동 점검 | 파이프라인 | 3~6번 항목 자동 체크 (길이·비율·빈칸·번호판 블러) |
| 딜러 확인 | 딜러 본인 | 사실표·나레이션·자막을 본 뒤 "확인" 응답 |
| 게시 | 딜러 또는 공식 계정 | 확인 응답 없으면 게시 금지 |

## 8. 가격 구조 (참고, 금액 미정)

노션 3번 상품안 기준. 무료 ②(모든 등록 매물에 자동 숏폼 1개) / 베이직 ③ 구독 / 프로 ③+ / 프리미엄 ④ 촬영. 금액과 월 건수는 사용자 결정 전까지 확정하지 않는다.
